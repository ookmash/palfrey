## Contesto

Serve decidere la chiave di derivazione degli ID ghost: per account o per space.

## Decisione

Per account. Conseguenza diretta di [[D11.3|ID stabile allo spostamento tra space]]: con chiave per space l'ID di un ghost cambierebbe spostando l'entità, contraddicendo la stabilità dell'ID.

## Stato

Deciso — sessione del 30/9/2026, come conseguenza di D11.3.

## Conseguenze

Riguarda anche le Raccolte-ghost (tag): convergono allo stesso ID ovunque nell'account vengano referenziate — vedi [[D11.5|Spazio di una Raccolta ghost]].
