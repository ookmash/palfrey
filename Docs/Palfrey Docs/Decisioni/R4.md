## Contesto

La condivisione tra persone (v1) richiede un modo per distribuire e revocare la chiave di uno space condiviso, senza un server fidato che possa farlo al posto degli utenti.

## Decisione

L'amministratore di uno space condiviso avvolge la chiave dello space per ogni membro e la ruota alla rimozione.

## Stato

Deciso.

## Conseguenze

Limiti accettati rispetto a MLS: un solo amministratore, nessuna post-compromise security continua. Il riferimento pubblico che copre questo requisito è dettagliato in [[D13|Riferimento pubblico per la rotazione delle chiavi]].
