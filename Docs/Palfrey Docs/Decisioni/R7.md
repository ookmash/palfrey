## Contesto

Il log append-only ([[Architettura]]) conserva ogni evento per sempre; serve un modo per rimuovere davvero il ciphertext dal server quando richiesto.

## Decisione

Cancellazione definitiva possibile: snapshot e compattazione, con rimozione del ciphertext dal server. Non è un costrutto crittografico né un protocollo di gruppo — è una procedura operativa su ciphertext già confezionato altrove, e non ricade sotto [[R8|Riferimento pubblico per ogni costrutto crittografico]].

## Stato

Deciso — sessione del 30/9/2026, dopo aver riqualificato la domanda come operativa invece che crittografica. Precedente diretto: Purge History API di Synapse/Matrix — cancellazione fisica autorizzata via API admin fino a un punto specificato, poi VACUUM per liberare lo spazio su disco. Dettaglio in [[R7 — precedente operativo per la cancellazione|Fonti]].

## Conseguenze

Sblocca [[D9|Autorizzazione dello snapshot e compattazione]] per la parte di autorizzazione.
