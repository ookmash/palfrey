Decisi esplicitamente. Da non riproporre senza un argomento nuovo.

- Nessuna primitiva crittografica e nessun protocollo di gruppo decentralizzato scritti da noi — vedi [[R8|Riferimento pubblico per ogni costrutto crittografico]].
- Nessuna rete P2P né servizio di terzi nel percorso dei dati o dei metadati — vedi [[R2|Nessun instradamento P2P o di terzi]].
- Nessun auth server proprio, nessun control plane, nessun installer multi-modalità.
- Nessuna adozione di prodotti terzi come parti della suite: le app si costruiscono.
- Nessun meta-modello universale di oggetti ("tutto è un Object con proprietà dinamiche"). Entità tipizzate concrete. Unica eccezione circoscritta: proprietà libere sulla Nota, stile frontmatter — non si estende per analogia.
- Nessun sistema di estensibilità dei moduli progettato prima del secondo modulo — vedi [[Shell-e-moduli]].
- Non è un prodotto per utenti sconosciuti finché non lo uso io stabilmente.

Framework di terzi valutati e scartati: vedi [[Spike-0a]].
